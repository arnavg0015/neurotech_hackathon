# Stimulation

This is the screen the participant sees during data collection. `stimulation.html` shows words and a fixation dot, and records the cue timestamps. EEG is recorded separately.

Open [stimulation.html](stimulation.html) in a browser. Set the trigger word, other words, timing, and session length, then press **Start**. Press Escape or the red stop button to end the session.

After the session, download the full CSV, trigger-only CSV, or JSON. The files go to the browser's download folder. Put the logs in the matching experiment and trial under [Stimulation Data](../data/Stimulation%20Data/readme.md).
