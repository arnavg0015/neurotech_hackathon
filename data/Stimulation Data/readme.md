# Stimulus logs

These are the cue logs from data collection, grouped by experiment and trial. `subject1_all.csv` contains every word and blank interval; `subject1_triggers.csv` contains only trigger cues. `subject1.json` holds session settings and event logs. The Baseline folder contains `subject1.csv` and `subject1.json`.

The [training notebooks](../../training/readme.md) align `_all.csv` timestamps with EEG samples. To collect more logs, open the [stimulation page](../../stimulation/stimulation.html).
