# Data

[EEG Data](EEG%20Data/readme.md) contains raw ANT Neuro recordings. [Stimulation Data](Stimulation%20Data/readme.md) contains the matching cue logs.

The [training notebooks](../training/readme.md) read spoken Experiment 2 and double-blink Experiment 3. Baseline and mental Experiment 1 recordings are kept here but are not used by the current models.
