# Two-channel blink model

This is the original Fp1/Fp2 logistic regression model used by the [demo](../../demo/readme.md). `blink_classifier.pkl` holds the model. The other files contain epochs, processed recordings, timing, splits, and results. The demo uses Trial 3.

Run the demo to use these saved files. The current blink training notebook writes the [21-channel analysis model](../blink_pipeline_all_channels/readme.md), not this variant; keep these bundled outputs for the demo.
